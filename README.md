In this Ultimate Tic Tac Toe Python File, you can play against 5 built-in AI'S:
1. Easy
2. Medium
3. Hard
4. Nightmare
5. Katrina
Katrina is a work in progress so she won't beat other AI's

There are multiple gamemodes:
1. Player vs Player
2. Player vs AI
3. AI vs AI

This Ultimate Tic Tac Toe Python file has mod support. 
IMPORTANT:
To make mods use the UTT_MOD_FORMAT.txt file
Make sure there is a folder called "Mods" in the same folder as your UTT.py file
